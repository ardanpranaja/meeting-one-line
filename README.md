The single sentence that could have replaced an entire pointless meeting:

> We just spent an hour scheduling a second meeting to decide what this meeting was supposed to decide.

## What main.ts does

`main.ts` holds the entry line as a constant, validates it against the competition gate (1–200 characters, exactly one line, not only whitespace), then writes it to `entry.txt` inside the output directory and logs the character count. The entry is 101 characters, one sentence, one line — comfortably inside the gate.

## Why this line

The line kills the meeting twice over: the first meeting decided nothing, and its only output was a second meeting about the same nothing. Anyone who has sat through a recursive meeting recognises it instantly.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the entry to `out/entry.txt`.
